# Search

Run Agent Sessions: Search Sessions or click the search icon in the Sessions view.

The search reads each file line by line in the extension host, so VS Code stays responsive. Click Cancel on the progress message to stop early and see the results found so far.

Pick a result to open the session at that turn. Your search words are already in the session's find box, with a count such as "2 of 5". Press Enter for the next match. Matches inside collapsed tool calls, outputs and diffs count too, and they open when you get to them.
