# Resume and export

- Resume in terminal opens a VS Code terminal in the session's project folder and types `claude --resume <id>` or `codex resume <id>` there. If that folder is gone, the terminal opens in the default folder and you get a note.
- Copy resume command copies the same command, with a `cd` to the project folder first.
- Export Markdown writes a `.md` file where you choose. Pick Export without tool outputs to leave out command output and file contents.

Transcripts can hold secrets. Read the export before you share it.
